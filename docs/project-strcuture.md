# Project Structure

Example:

```text
MyApp/
├── src/
│   ├── java/
│   │   └── com/example/app/
│   │       └── MainActivity.java
│   │
│   ├── res/
│   │   └── layout/
│   │       └── activity_main.xml
│   │
│   ├── assets/
│   │
│   ├── cpp/
│   │   ├── src/
│   │   ├── include/
│   │   └── native.build
│   │
│   └── AndroidManifest.xml
│
├── libs/
│
├── vexel.build
│
└── build/
```

## Important Directories

### src/java

Java source code.

### src/res

Android resources.

### src/cpp

Native source code.

### src/assets

Files packed into APK assets.

### libs

Additional libraries.

### build/output

Generated build output.
